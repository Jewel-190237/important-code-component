# Important Code Components - Reusable React Components

A collection of reusable React components for various UI patterns including sliders, navigation, tabs, and more. Built with React and Tailwind CSS.

## Features

- Reusable React components
- Tailwind CSS styling
- Dark mode support
- Responsive design
- Multiple slider variants
- Modern UI patterns

## Components

### CommonSlider
- Hero/banner section slider
- Animated buttons
- Smooth transitions

### Navbar
- Recessive navigation design
- Responsive mobile menu
- Modern UI patterns

### Footer
- Site footer component
- Responsive layout
- Contact information

### Login
- Authentication form
- User login interface
- Form validation

### Tab
- Tabbed interface component
- Dynamic content switching
- Responsive design

### ShapeWithBorder
- Decorative shape component
- Border styling options
- Customizable appearance

### ThreeChangeSlider
- Multi-slide display
- Three slides on screen
- Interactive navigation

### Team
- Swiper slider for team members
- Responsive carousel
- Member profiles

### ThemeControl
- Dark mode toggle
- Theme switching
- User preferences

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Jewel-190237/important-code-component.git
   ```

2. Copy the desired components into your project

3. Install required dependencies:
   ```bash
   npm install swiper react-icons
   ```

4. Add dark mode support to your `tailwind.config.js`:
   ```javascript
   module.exports = {
     darkMode: 'class',
     // ... other config
   }
   ```

## Usage

### CommonSlider
```jsx
import CommonSlider from './CommonSlider';
```
